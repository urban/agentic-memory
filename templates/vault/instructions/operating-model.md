# Operating Model

## Startup

1. Read `AGENTS.md`.
2. Read `MEMORY_SYSTEM.md`.
3. Read `MEMORY.md`.
4. Read this instruction map only as needed.
5. Follow MOC routing links using `Read when:` conditions.

## Progressive disclosure

Load the smallest useful context:

1. root memory
2. relevant MOC
3. specific atomic note
4. source or output only if needed

Do not load entire folders by default.

## Session close

Before finishing substantial work:

- decide whether any durable memory should be saved
- update the smallest correct file
- update `updated` dates on material edits
- ensure MOCs still route correctly
- summarize changes clearly
- check Git status when practical
