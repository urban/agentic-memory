# AGENTS

Agentic Memory vault entrypoint.

## Read first

1. `MEMORY_SYSTEM.md`
2. `MEMORY.md`
3. `instructions/README.md`

Then load only the relevant instruction, MOC, or note files for the task.

## Operating principle

Use progressive disclosure:

`AGENTS.md` → `MEMORY_SYSTEM.md` → `MEMORY.md` → relevant MOC → specific atomic notes → sources only when needed.

## Core rules

- Keep `MEMORY.md` lean; it is core memory and the root MOC.
- Use MOCs as routing surfaces, not content dumps.
- Use atomic notes as graph leaves.
- Use semantic links to connect atomic notes.
- Keep sources immutable after capture.
- Save durable artifacts in `outputs/`.
- Update the smallest correct layer.
- Preserve human authorship and source/synthesis boundaries.
- If work is substantial, consider whether Reflection is needed.
