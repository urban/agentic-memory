# Atomic Notes as Knowledge Units

Atomic notes are the smallest durable knowledge units in Agentic Memory. Each note should contain one reusable idea, decision, pattern, preference, heuristic, or question.

When the same observation repeats across projects, promote it from project memory into an atomic note so it can become a single source of truth.

## Use when

- Creating, splitting, merging, or evaluating notes.
- Deciding whether a note is focused enough to be reusable.
- Promoting repeated project observations into reusable knowledge.

Atomic notes should mature from `seedling` toward `evergreen`, with 3+ meaningful semantic links as one sign of maturity.
